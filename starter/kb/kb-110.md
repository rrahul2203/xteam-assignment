# Phishing and Suspicious Messages

We never ask for your password, recovery phrase or a one time code, and we
never ask you to move funds to a holding wallet for safekeeping. Any message
doing so is fraudulent, whatever the sender address appears to be. Report
suspicious messages from the in-app Report activity flow. Links in email
should be checked against the official domain before being opened, and support
will never initiate contact asking you to install remote access software.
