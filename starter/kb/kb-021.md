# Two-Factor Authentication Recovery

If you have lost your phone or lost access to your authenticator app, you can
recover two-factor authentication using an SMS backup code sent to the phone
number registered on your account. Request the backup code from the login
screen, enter it, and then re-enrol a new authenticator device. For security,
two-factor authentication recovery is subject to a 24 hour waiting period,
during which withdrawals are disabled. If you no longer control the registered
phone number, contact support to begin manual identity verification.
