# API Deprecation Notice

Version 1 of the public API is deprecated and will stop responding on
2027-01-15. All endpoints have a v2 equivalent documented in the developer
portal. v1 keys continue to work until the shutdown date, but no new v1 keys
are being issued. Rate limits on v1 are frozen at their current values and
will not be raised. We recommend migrating well before the shutdown date, as
no extension is planned.
