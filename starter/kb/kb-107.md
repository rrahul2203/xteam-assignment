# Public API Rate Limits

Unauthenticated requests to public endpoints are limited to 100 requests per
minute per IP address. Authenticated requests are limited to 1,000 requests
per minute per API key. Exceeding a limit returns HTTP 429 with a Retry-After
header. Sustained abuse can result in the key being suspended. Websocket
subscriptions are counted separately and are limited to 50 concurrent channels
per key.
